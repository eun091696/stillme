## Overview

10명이 동시에 개발할 때 충돌과 품질 편차를 줄이는 코딩 표준입니다.

## Goals

- 안정성과 유지보수성을 우선합니다.
- 팀 간 계약과 책임을 명확히 합니다.

## Requirements

- 기존 기능과 문서 내용을 보존합니다.
- 변경 시 관련 문서와 검증 결과를 함께 갱신합니다.

## Implementation

기능별 모듈 경계, 명시적 타입, 작은 Pull Request, 자동 검사, 변경 문서 동기화를 필수로 합니다.

## Checklist

- [ ] 책임 Agent가 내용을 검토했다.
- [ ] 구현 또는 운영 상태와 문서가 일치한다.
- [ ] 관련 변경 시 이 문서를 함께 갱신한다.
