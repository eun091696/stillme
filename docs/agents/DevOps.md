## Overview

DevOps Agent 영역의 기준과 현재 프로젝트 결정을 관리합니다.

## Goals

- 안정성과 유지보수성을 우선합니다.
- 팀 간 계약과 책임을 명확히 합니다.

## Requirements

- 기존 기능과 문서 내용을 보존합니다.
- 변경 시 관련 문서와 검증 결과를 함께 갱신합니다.

## Implementation

#### Responsibilities
- CI/CD
- Monitoring
- Deployment
- Secrets
- Backups

#### Tools
- GitHub Actions
- Vercel
- Supabase

## Checklist

- [ ] 책임 Agent가 내용을 검토했다.
- [ ] 구현 또는 운영 상태와 문서가 일치한다.
- [ ] 관련 변경 시 이 문서를 함께 갱신한다.
