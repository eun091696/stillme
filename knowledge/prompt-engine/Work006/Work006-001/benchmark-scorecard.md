# Benchmark Scorecard

## 평가표

| 항목 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 동일인 유지 | 다른 사람 | 닮았으나 확신 어려움 | 즉시 같은 사람으로 인식 |
| 얼굴 구조 유지 | 다수 핵심 구조 변경 | 경미한 비율 변화 | 얼굴형·눈·코·입·턱 비율 유지 |
| 피부 유지 | 피부 재생성·톤 대변화 | 일부 질감·특징 손실 | 톤·질감·모공·고유 특징 유지 |
| 헤어 유지 | 스타일·헤어라인 변경 | 일부 볼륨·경계 변화 | 헤어라인·가르마·길이·볼륨 유지 |
| 표정 유지 | 감정·입·눈이 변경 | 미세한 인상 변화 | 원본 표정과 인상 유지 |
| 자연스러움 | AI 렌더·심각한 경계 오류 | 사용 가능하나 인공 흔적 | 실제 촬영처럼 자연스러움 |
| 요청 수행 | 핵심 요청 미수행 | 부분 수행·부수 변경 | 허용 범위 안에서 정확히 수행 |

2점과 4점은 인접 기준 사이의 상태에 부여한다.

## 자동 판정

- 총점 31점 이상 + 동일인 유지 5점 + 얼굴 구조 유지 5점: `Pass`
- 그 외: `Fail`
- 실행 조건 불일치 또는 평가 불가: `Inconclusive`
- Case 통과는 Prompt 또는 Rule 승인을 뜻하지 않는다.
