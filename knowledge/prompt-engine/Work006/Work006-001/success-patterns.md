# Success Patterns

## 공통 성공 패턴

| 코드 | 성공 패턴 | 관찰 증거 |
|---|---|---|
| S-ID-01 | 동일인 즉시 인식 | 원본과 결과가 같은 사람으로 주저 없이 판정됨 |
| S-GEO-01 | 구조 잠금 | 얼굴형·턱·눈·코·입의 형태와 비율이 유지됨 |
| S-SKIN-01 | 피부 연속성 | 피부톤·질감·모공·고유 특징이 조명 변화 안에서 유지됨 |
| S-HAIR-01 | 헤어 연속성 | 헤어라인·가르마·길이·볼륨·질감이 유지됨 |
| S-EXP-01 | 표정 연속성 | 입·눈·볼과 전체 인상이 원본과 같음 |
| S-SRC-01 | 원본 우선 | 스타일 요구가 잠금 속성을 덮어쓰지 않음 |
| S-BND-01 | 정밀 편집 | 허용된 요소만 바뀌고 잠긴 요소는 동일함 |
| S-NAT-01 | 사진 자연스러움 | 피부·빛·경계가 실제 촬영처럼 이어짐 |
| S-REQ-01 | 정확한 요청 수행 | 목표 변경이 완전하고 부수 변경이 없음 |

## 카테고리 성공 패턴

- **비즈니스 프로필:** 동일 얼굴 위에 정장·배경·조명만 전문적으로 통합되고 목·칼라 경계가 자연스럽다.
- **학생증:** 실제 나이와 정체성을 유지하며 단정하지만 특정 학교·교복·로고를 발명하지 않는다.
- **자연 프로필:** 새 미소나 뷰티 필터 없이 친근한 배경과 조명이 자연스럽게 통합된다.

## 성공 인정 제한

- 한 장이 좋아 보여도 동일 조건 반복에서 게이트를 모두 통과해야 한다.
- 미적 선호가 높아도 동일인 또는 얼굴 구조가 4점 이하이면 성공이 아니다.
- Case Pass는 Candidate Rule의 Phase 1 근거이며 Approved 상태가 아니다.
