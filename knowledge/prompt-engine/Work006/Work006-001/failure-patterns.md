# Failure Patterns

| 코드 | 유형 | 실패 판정 예시 | 우선 Action |
|---|---|---|---|
| F-ID-01 | 동일인 | 다른 사람처럼 보임 | 해당 조건 Fail, Identity 실험 재검토 |
| F-GEO-01 | 턱·얼굴형 | 턱선·광대·얼굴 폭 변경 | R003 속성 범위 재검토 |
| F-GEO-02 | 눈 | 크기·간격·모양 변경 | 특징점별 기록 후 fixture 확대 |
| F-GEO-03 | 코·입 | 코 형태·입술 비율 변경 | 구조 Rule과 표정 Rule 충돌 확인 |
| F-SKIN-01 | 피부 재생성 | 원본 피부 대신 새 피부 | R007/R008 분리 실험 |
| F-SKIN-02 | 특징 증감 | 모공·얼룩 추가 또는 제거 | retouch intensity 확인 |
| F-SKIN-03 | 피부톤 | 밝기·색조·민족적 특성 변화 | 조명 confound 분리 |
| F-HAIR-01 | 헤어 구조 | 헤어라인·가르마 변경 | R005 재검증 |
| F-HAIR-02 | 헤어 양감 | 길이·볼륨·질감 변경 | grooming delta와 분리 |
| F-EXP-01 | 미소 | 요청하지 않은 미소·눈웃음 | R004/R011 표현 비교 |
| F-EXP-02 | 입·치아 | 입 모양 변경·치아 생성 | 표정 envelope 축소 |
| F-SRC-01 | 원본 이탈 | 원본보다 텍스트 스타일을 우선 | R001 위치 실험으로 회귀 |

| F-NAT-01 | 인공 질감 | 뷰티 필터·플라스틱 피부·렌더 느낌 | 피부·조명 Rule 분리 |
| F-EDGE-01 | 경계 | 헤어 halo, 목·칼라 붕괴 | 배경·의상 통합 Rule 분리 |
| F-BIZ-01 | 비즈니스 | 정장 변경과 함께 얼굴 변경 | CASE-007 후 EXP-010 재실행 |
| F-STU-01 | 학생증 나이 | 어려 보이게 재생성 | apparent age 잠금 확인 |
| F-STU-02 | 허위 학교성 | 교복·로고·특정 학교 요소 생성 | category 범위 축소·guard 검토 |
| F-REQ-01 | 요청 미수행 | 목표 의상·배경·조명 누락 | Rule 충돌과 과도한 잠금 확인 |

## 실패 기록 원칙

- 한 결과에 여러 코드를 붙일 수 있다.
- 동일인 또는 얼굴 구조 실패는 총점과 무관하게 Fail이다.
- 원인 추정과 관찰 사실을 분리한다.
- 모델별 실패율을 합치지 않는다.
- 실패 시 Prompt를 즉시 수정하지 않고 해당 Work005 실험으로 되돌려 후속 실험을 설계한다.
