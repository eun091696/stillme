# Validation Checklist

## 실행 전

- [ ] 입력이 Work005-001과 Work005-002에서 정의된 Rule/실험인가
- [ ] 실제 Prompt 신규 작성이나 Prompt Engine 수정이 없는가
- [ ] Case 내 A/B가 동일 원본을 사용하는가
- [ ] 변경 변수는 정확히 하나인가
- [ ] 모델·버전·출력 설정·비율·해상도가 동일한가
- [ ] 요청·고정 Rule·Rule 순서가 동일한가
- [ ] 조건별 최소 2회 반복이 준비됐는가
- [ ] NB2와 Pro 결과를 분리 기록하는가
- [ ] 원본 사용 동의와 source ID가 기록됐는가

## 실행 중

- [ ] condition ID와 variant hash를 기록했는가
- [ ] 생성 순서 또는 평가 순서 편향을 통제했는가
- [ ] 후처리를 적용하지 않았는가
- [ ] 누락·오류 출력은 점수 대신 Inconclusive로 기록했는가
- [ ] 실행 조건 이탈을 즉시 표시했는가

## 평가

- [ ] 원본과 결과를 나란히 확인했는가
- [ ] 7개 항목 모두 1~5점으로 평가했는가
- [ ] 관찰 근거와 실패 코드를 남겼는가
- [ ] 동일인 유지가 5점인가
- [ ] 얼굴 구조 유지가 5점인가
- [ ] 총점이 31점 이상인가
- [ ] 반복 결과 전부에서 필수 게이트를 통과했는가
- [ ] 카테고리 적합성이 아닌 `요청 수행` 기준으로 채점했는가

## 평가 후

- [ ] Case/모델별 평균·최저점·실패 코드를 집계했는가
- [ ] NB2와 Pro 점수를 혼합하지 않았는가
- [ ] 단일 변수 원칙 위반 Case를 재실행 대상으로 분리했는가
- [ ] 실패 시 지정된 Work005 실험 Action으로 연결했는가
- [ ] Pass를 Approved Rule 또는 Runtime 반영으로 오해하지 않았는가
- [ ] Prompt·Builder·Registry·Module을 수정하지 않았는가

## Phase 1 완료 조건

- [ ] CASE-001~010 모두 실행 기록이 존재한다
- [ ] 모든 Case에 A/B, 반복, 모델별 Scorecard가 존재한다
- [ ] 모든 Pass가 31점 이상이며 identity=5, facialGeometry=5다
- [ ] 실패 패턴과 성공 패턴이 코드로 연결됐다
- [ ] 다음 단계는 사람 Review 또는 추가 Validation이며 자동 승인이 아니다
